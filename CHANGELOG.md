# Changelog

## 1.0.0 — 2026-11-17
First public release.
- Public lobby and code-joined private rooms, no login, in-memory only
- Moderation: owner kick/lock, admin ban/clear/announce, word filter, lobby link blocking, `/report`
- `/me`, `/nick`, typing indicator, clickable safe links, unread counter in the tab title
- Monetization: donate button, self-hosted sponsor banner, Google AdSense (strict nonce CSP, auto `ads.txt`)
- Live online counter, invite links, mobile layout
- Hardened Docker image, CI, multi-arch GHCR publishing
